#  RYU TECNOLOGÍA - Panel Multimedia

Plataforma web estática diseñada para la navegación y acceso rápido a contenido multimedia y aplicaciones optimizadas para entornos web y dispositivos Android TV.

## 🚀 Características

* **Interfaz Glassmorphism:** Diseño moderno con efectos translúcidos y desenfoques elegantes.
* **Modo Adaptable:** Opciones de visualización optimizadas tanto para PC como para Android TV.
* **Indicadores Visuales:** Alertas integradas para identificar compatibilidad de plataformas de reproducción.
* **Reloj y Fecha en Tiempo Real:** Componente dinámico integrado en la cabecera.

## 🛠️ Tecnologías Utilizadas

* **HTML5** (Estructura semántica)
* **CSS3 / Flexbox** (Estilos, diseño responsivo y efectos visuales)
* **JavaScript (Vanilla)** (Funcionalidad de reloj y lógica dinámica)
